# ☁️ Student Management System (AWS Deployed)

A full-stack Student Management System built using React, Node.js, and MySQL, deployed on AWS using EC2, RDS, and S3.

---

## 🚀 Project Overview

This project demonstrates real-world cloud deployment:

* Backend hosted on EC2
* Database managed via RDS
* Frontend hosted on S3

---

## 🌐 Live Demo

> ⚠️ Note: The live deployment has been stopped to avoid AWS charges.

## ☁️ AWS Deployment Summary

* Deployed backend on EC2 instance
* Connected backend with RDS MySQL database
* Hosted frontend on S3 bucket
* Configured security groups and environment variables
* Managed backend using PM2
